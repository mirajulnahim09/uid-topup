## 4. Middleware

`src/middleware.ts` — runs on every request except static assets (`_next/static`, `_next/image`, `favicon.ico`, `robots.txt`, and common image extensions).

1. **Route protection:** if path starts with `/admin` or `/account`, requires a valid NextAuth JWT (`getToken`); redirects to `/login?callbackUrl=<path>` if absent. If path starts with `/admin`, additionally requires `token.role === 'ADMIN'`, redirecting to `/` otherwise.
2. **Security headers:** sets CSP, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`, `X-DNS-Prefetch-Control: off`, `Cross-Origin-Opener-Policy`/`Cross-Origin-Resource-Policy: same-origin`, `X-Permitted-Cross-Domain-Policies: none`, and (production only) `Strict-Transport-Security`. Deletes `X-Powered-By`/`Server` headers.

| Model | Key fields | Purpose |

| `SocialLink` | `platform`, `url`, `label`, `sortOrder`, `isActive` | Footer/site social links |
| `PaymentChannel` | `method` (BKASH/NAGAD/ROCKET/UPAY), `accountNo`, `accountType`, `instruction` | Manual payment destination shown to customers |
| `Coupon` | `code`(unique), `type` (PERCENT/FIXED), `value`, `minOrder`, `maxDiscount`, `usageLimit`, `usageCount`, `perUserLimit`, `startsAt`, `expiresAt` | Discount code |
| `CouponUse` | `couponId`, `userId`, `orderId`, `discount` | Per-use record, enforces per-user limits |
| `Deposit` | `depositNo`(unique, autoincrement), `method`, `amount`, `trxId`(unique), `senderNo`, `screenshot`, `status` (PENDING/APPROVED/REJECTED), `adminNote`, `reviewedAt` | Manual top-up claim |
| `Order` | `orderNo`(unique, autoincrement), `variantId`, `playerUid`, `playerName`, `subtotal`, `discount`, `price`, `productName`/`variantName` (snapshot), `couponId`, `status` (PENDING/PROCESSING/COMPLETED/FAILED/REFUNDED), `adminNote`, `internalNote` (admin-only) | Customer order |
| `LedgerEntry` | `type` (DEPOSIT/ORDER/REFUND/ADMIN_ADJUST/REFERRAL_BONUS), `amount`, `balanceAfter`, `refId` | Immutable balance-change audit trail |
| `Notification` | `title`, `body`, `link`, `isRead` | In-app user notification |

`prisma/constraints.sql` adds Postgres `CHECK` constraints (non-negative balance/price/amount, `discount ≤ subtotal`, coupon `value` bounds) — applied via a separate manual script, not part of `db:push`/`db:setup` (see `AUDIT_REPORT.md` H2).

## 8. Environment Variables

From `.env.example` and `src/lib/env.ts`:

| Variable | Required? | Purpose |
|---|---|---|
| `DATABASE_URL` | **Required** | Postgres connection string (validated to start with `postgres(ql)://`) |
| `NEXTAUTH_SECRET` | **Required** | JWT signing secret (validated ≥24 chars) |
| `NEXTAUTH_URL` | Required in production | Canonical site URL for NextAuth callbacks |
| `BLOB_READ_WRITE_TOKEN` | Optional | Vercel Blob storage token — image upload disabled if absent |
| `RESEND_API_KEY` | Optional | Resend email API key — transactional email disabled if absent |
| `EMAIL_FROM` | Optional | From-address for outgoing email |
| `ADMIN_EMAIL` | Seed-time only | Seeded admin account email (`prisma/seed.ts`) |
| `ADMIN_PASSWORD` | Seed-time only | Seeded admin account password (`prisma/seed.ts`) — must be changed before going live |
| `GOOGLE_CLIENT_ID` | Optional | Google OAuth — login provider disabled if absent |
| `GOOGLE_CLIENT_SECRET` | Optional | Google OAuth — login provider disabled if absent |

`assertEnv()` (`src/lib/env.ts`) throws at first `prisma` access if a required var is missing/invalid; warns (non-fatal) in development if an optional var is missing.

## 9. Admin Features (functional summary)

- Review, approve, or reject manual deposit claims with an audit note
- Complete or fail-and-auto-refund customer orders
- View/search all customers; adjust balance (+/-) with a required reason; ban, suspend, or reinstate accounts; promote/demote admin role
- Full CRUD on categories, products, variants (price/cost/stock/popularity)
- Full CRUD on coupons (percent/fixed, usage limits, per-user limits, expiry)
- Full CRUD on homepage banners, social links, payment channel numbers
- Site-wide settings (site name, notice, hero copy, deposit min/max, referral bonus config, support contact info)
- Send announcements (creates notifications for targeted/all users)
- View sales/revenue reports
- View the full `AdminLog` audit trail (who did what, when, from which IP)
- Export a full JSON backup of the database; import/restore from a backup JSON
- Toggle site-wide maintenance mode

## 10. Customer Features (functional summary)

- Browse products by category, search products, view product/variant detail
- Register (email+password) or sign in with Google
- Reset a forgotten password via emailed token
- Submit manual deposit claims (bKash/Nagad/Rocket/Upay) with transaction ID and screenshot
- Place orders against wallet balance, optionally applying a coupon
- Track order status in real time (auto-refreshing detail page) through pending → processing → completed/failed/refunded
- View order history, including a separate view for subscription-style ("smm") orders
- View and manage in-app notifications
- Edit profile (name/phone; email is immutable)
- View referral code and referral bonus status; earn a bonus when a referred user's first qualifying deposit is approved
