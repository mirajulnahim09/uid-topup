# UID TopUp

ফ্রি ফায়ার ডায়মন্ড টপ আপ সাইট — **ম্যানুয়াল সিস্টেম**।
কাস্টমার bKash এ টাকা পাঠাবে → আপনি হাতে যাচাই করে ব্যালেন্স দেবেন →
কাস্টমার অর্ডার করবে → আপনি হাতে গেমে টপ আপ দেবেন।

# 🚀 চালু করা — ধাপে ধাপে

## ধাপ ১ — Node.js আছে কিনা দেখুন

```bash
node -v
```

`v18` বা তার বেশি দেখালে ঠিক আছে। না থাকলে [nodejs.org](https://nodejs.org) থেকে LTS নামান।

---

## ধাপ ২ — প্রজেক্ট ইনস্টল

```bash
unzip uid-topup-final.zip
cd v2
npm install
```

⏳ ২–৩ মিনিট লাগবে।

---

## ধাপ ৩ — ফ্রি ডাটাবেস বানান

1. [neon.tech](https://neon.tech) এ যান → **Sign up** (ফ্রি, কার্ড লাগে না)
2. **Create Project** → নাম দিন `uidtopup`
3. **Connection string** কপি করুন — দেখতে এমন:
   ```
   postgresql://user:pass@ep-xyz-123.ap-southeast-1.aws.neon.tech/neondb?sslmode=require
   ```

---

## ধাপ ৪ — `.env` ফাইল বানান

```bash
cp .env.example .env
```

`.env` ফাইলটা খুলে দুইটা জিনিস বসান:

```bash
# ধাপ ৩ এর connection string
DATABASE_URL="postgresql://user:pass@ep-xyz.neon.tech/neondb?sslmode=require"

# এই কমান্ড চালিয়ে যা আসবে সেটা বসান:
#   openssl rand -base64 32
NEXTAUTH_SECRET="এখানে র‍্যান্ডম স্ট্রিং বসান"

NEXTAUTH_URL="http://localhost:3000"
```

> **Windows এ `openssl` না থাকলে** — যেকোনো ৩২+ অক্ষরের এলোমেলো লেখা বসান।
> (কিন্তু লাইভে যাওয়ার আগে অবশ্যই আসল random বানাবেন।)

## ধাপ ৫ — ডাটাবেস তৈরি

```bash
npm run db:push      # টেবিল বানায়
npm run db:seed      # প্রোডাক্ট, দাম, অ্যাডমিন অ্যাকাউন্ট বসায়
```

### ★ সুরক্ষা গার্ড বসান (দরকারি)

```bash
psql "$DATABASE_URL" -f prisma/constraints.sql
```

এটা ডাটাবেসেই নিয়ম বসিয়ে দেয় — ব্যালেন্স negative হতে পারবে না, দাম negative হতে পারবে না।
**শেষ রক্ষাকবচ।**

> `psql` না থাকলে: Neon ড্যাশবোর্ড → **SQL Editor** → `prisma/constraints.sql` ফাইলের
> লেখাটা কপি-পেস্ট করে **Run** চাপুন।

# ▲ Vercel এ লাইভ করা

1. কোড GitHub এ push করুন
2. [vercel.com](https://vercel.com) → **Import Project**
3. **Environment Variables** এ বসান:

   | Key | Value |
   |---|---|
   | `DATABASE_URL` | Neon connection string |
   | `NEXTAUTH_SECRET` | `openssl rand -base64 32` |
   | `NEXTAUTH_URL` | `https://your-site.vercel.app` |
   | `BLOB_READ_WRITE_TOKEN` | ছবি আপলোডের জন্য (নিচে দেখুন) |
   | `RESEND_API_KEY` | ইমেইলের জন্য (ঐচ্ছিক) |

4. **Deploy** চাপুন

### ছবি আপলোড চালু করা

Vercel Dashboard → **Storage** → **Create Database** → **Blob** →
token কপি করে `BLOB_READ_WRITE_TOKEN` এ বসান।

> এটা না দিলেও সাইট চলবে — শুধু ছবি আপলোড হবে না।

### ইমেইল চালু করা (ঐচ্ছিক)

[resend.com](https://resend.com) → ফ্রি অ্যাকাউন্ট → API key → `RESEND_API_KEY`

> না দিলে ইমেইল যাবে না, কিন্তু in-app নোটিফিকেশন কাজ করবে।

# 📖 রোজকার কাজ

## টাকা যোগের রিকোয়েস্ট এলে

1. Admin → **হোম** — পেন্ডিং রিকোয়েস্ট দেখাবে
2. **স্ক্রিনশট** দেখুন (ক্লিক করলে বড় হয়)
3. **TrxID** কপি করুন (ক্লিক করলেই কপি হয়)
4. **bKash অ্যাপে গিয়ে TrxID মিলিয়ে দেখুন** ← সবচেয়ে জরুরি
5. মিলে গেলে **✓ টাকা যোগ করুন** চাপুন
6. না মিললে **✕** চেপে কারণ লিখুন

## অর্ডার এলে

1. Admin → **হোম** — অর্ডার দেখাবে
2. **Player UID** ক্লিক করে কপি করুন
3. গেমে গিয়ে টপ আপ দিন
4. **✓ টপ আপ দিয়েছি** চাপুন
5. দিতে না পারলে **✕** — **টাকা + স্টক + কুপন সব নিজে থেকেই ফেরত যাবে**

## দাম বদলাতে

Admin → 🏷️ প্রোডাক্ট ও দাম → প্রোডাক্টে ক্লিক → **✎ এডিট** → নতুন দাম → Enter

> পুরনো অর্ডারে পুরনো দামই থাকবে — হিসাব ঠিক থাকবে।

## ঝামেলা হলে — কে কী করেছে দেখুন

Admin → **📋 লগ**

ইউজার বলল "আমার ৳৫০০ কেটে নেওয়া হয়েছে কিন্তু ডায়মন্ড পাইনি"?
লগে দেখুন — কোন অ্যাডমিন, কখন, কোন IP থেকে, কী করেছে। সব রেকর্ড আছে।

# 🔒 নিরাপত্তা — যা টেস্ট করা হয়েছে

আসল PostgreSQL বসিয়ে **২০৬টা টেস্ট** চালানো হয়েছে, সব পাস:

| আক্রমণ | ফলাফল |
|---|---|
| একসাথে ১০ ট্যাব থেকে অর্ডার (double-spend) | ✓ আটকায় — row lock |
| ৫ জন অ্যাডমিন একসাথে approve | ✓ ঠিক ১ বার টাকা যোগ হয় |
| ৫ বার refund চাপা | ✓ ঠিক ১ বার ফেরত যায় |
| ২০ জন একই TrxID claim | ✓ ঠিক ১ জন পায় |
| ৩টা স্টকে ৫ জন একসাথে | ✓ ৩ জন কেনে, স্টক ০ |
| শেষ কুপন ৩ জন একসাথে | ✓ ঠিক ১ জন পায় |
| ১০০% ছাড় / ছাড় > দাম | ✓ দাম ৳০, negative হয় না |
| negative দামের প্যাকেজ | ✓ আটকায় — ব্যালেন্স বাড়ে না |
| ব্যান করা ইউজারের অর্ডার | ✓ আটকায়, টাকা অক্ষত |
| ১ পয়সা কম ব্যালেন্স | ✓ আটকায় |
| **৳৬০০০ ঢুকিয়ে ৩০ জনের chaos test** | ✓ **এক পয়সাও তৈরি হয়নি** |

**হিসাব সবসময় মেলে:** `যা ঢুকেছে = যা ওয়ালেটে আছে + যা খরচ হয়েছে`

### আরও যা আছে

| সুরক্ষা | বিবরণ |
|---|---|
| **লগইন ব্রুট-ফোর্স গার্ড** | একই IP: ১০ মিনিটে ১০ বার · একই ইমেইল: ১৫ মিনিটে ৫ বার |
| **টাইমিং অ্যাটাক গার্ড** | ইমেইল আছে কিনা সময় দেখে বোঝা যায় না (ডামি হ্যাশ) |
| **অ্যাডমিন অডিট লগ** | কে কখন কত টাকা approve/refund/adjust করল — সব রেকর্ড (📋 লগ পেজ) |
| **শক্ত পাসওয়ার্ড** | ৮+ অক্ষর, অন্তত ১টি সংখ্যা, ৩২টি দুর্বল পাসওয়ার্ড ব্লক |
| **XSS sanitize** | `< > " ' \`` সব মুছে যায়। `//evil.com` redirect আটকায় |
| **ফাইল আপলোড** | Magic-byte চেক — PHP shell / SVG script / ELF নাম বদলে দিলেও ধরা পড়ে |
| **secure cookie** | httpOnly (XSS হলেও টোকেন চুরি হবে না) · SameSite · HTTPS-only |
| **CSP header** | script-src, frame-ancestors, object-src, form-action সব লক করা |
| **DB constraint** | ব্যালেন্স/দাম negative হতে *পারবেই না* — ডাটাবেস নিজেই আটকাবে |
| **ban গার্ড** | ব্যান করলে পুরনো JWT সাথে সাথে বাতিল |

# ❓ সমস্যা হলে

**`npm run db:push` কাজ করছে না**
→ `.env` এ `DATABASE_URL` ঠিক আছে কিনা দেখুন। `?sslmode=require` শেষে আছে তো?

**লগইন হচ্ছে না**
→ `NEXTAUTH_SECRET` বসিয়েছেন? `npm run db:seed` চালিয়েছেন?

**ছবি আপলোড হচ্ছে না**
→ `BLOB_READ_WRITE_TOKEN` লাগবে (Vercel → Storage → Blob)

**"এই প্যাকেজের দামে সমস্যা আছে"**
→ কোনো প্যাকেজের দাম negative হয়ে গেছে। Admin → প্রোডাক্ট → ঠিক করুন।
